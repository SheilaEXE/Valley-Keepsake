VALLEY KEEPSAKE FOR macOS — EXPERIMENTAL

This build has not been tested in normal gameplay on a Mac. It is provided for
early testing on macOS 14 or newer. Choose the Apple Silicon ZIP for M1/M2/M3/M4
or newer chips, or the Intel ZIP for an Intel Mac.

Extract the ZIP and move Valley Keepsake.app to Applications (or another folder).
Open it, then choose your translation library, settings library, and Stardew
Valley Mods folder. The default Steam Mods location is under:
~/Library/Application Support/Steam/steamapps/common/Stardew Valley/Contents/MacOS/Mods

The app includes .NET and does not need a separate .NET installation. It is
ad-hoc signed for packaging checks, but it is not signed with an Apple Developer
ID or notarized. macOS may block the first launch. If you trust this download,
try opening the app and then use System Settings > Privacy & Security > Open
Anyway. Do not disable Gatekeeper for the entire system.

Apple's instructions: https://support.apple.com/en-us/102445

Please report the macOS version, chip type, and any launch error if it fails.
